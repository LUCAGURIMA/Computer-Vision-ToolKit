# 🚀 YOLOv8 Training

Estrutura simples para treinar modelos de classificação e segmentação.

## 📁 Estrutura

```
training/
├── classification/
│   ├── classification_training.ipynb  ← Abra isto
│   ├── dataset/                       ← Copie seu dataset aqui
│   └── README.md
├── segmentation/
│   ├── segmentation_training.ipynb    ← Abra isto
│   ├── dataset/                       ← Copie seu dataset aqui
│   └── README.md
└── README.md (este arquivo)
```

## 🚀 Rápido

### Classificação

```bash
1. Copie dados para: training/classification/dataset/
2. jupyter notebook training/classification/classification_training.ipynb
3. Execute células em ordem
```

### Segmentação

```bash
1. Copie dados para: training/segmentation/dataset/
2. jupyter notebook training/segmentation/segmentation_training.ipynb
3. Execute células em ordem
```

## 📖 Detalhes

- Veja `classification/README.md` para classificação
- Veja `segmentation/README.md` para segmentação

## ✅ Pronto!

Tudo que você precisa está nas duas pastas.
